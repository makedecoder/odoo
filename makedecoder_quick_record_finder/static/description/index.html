A familiar flow

From a reference to a record.
In three simple steps.

Stay in your current workspace. Search supported records through Odoo’s existing command palette.

01

Open the palette

Press Ctrl + K. Your native menu navigation is still available in the same place.

02

Type what you know

Start with /, then a name or reference. Try /S00007, a contact email or a product code.

Get started

A straightforward setup.

Requires Odoo 20 and the Web module. Install in your custom addons directory.

  1. Place makedecoder_quick_record_finder inside a directory on your addons path.
  2. Restart Odoo, enable developer mode and update the Apps list.
  3. Remove the default Apps filter, find Quick Record Finder and install it.
  4. Refresh with Ctrl + Shift + R, then try Ctrl + K → /reference.
Good to know

A few useful details.

Does this search every field and attachment?

Search covers configured names and reference fields on supported models. It does not provide full-text search across every field or attachment.

Can users find restricted records?

Search uses the current user’s access rights and record rules without superuser searches. Public and portal users cannot call record search.

Will this install additional business applications?

The addon depends only on Web. Sales, Purchase and other optional applications are searched only if already installed.

Can developers add another model?

A technical addon can extend global.record.search._search_models() to include additional business models and searchable fields.
